# Accessibility Rules

- Use semantic HTML elements (<nav>, <main>, <article>, <section>, <aside>, <footer>)
- All images must have alt text
- Interactive elements need focus styles (focus:ring-2)
- Color contrast meets WCAG AA standards
- Forms have proper labels associated with inputs
- Buttons have aria-labels when icon-only
- Skip-to-content link for keyboard users
- Dark mode maintains sufficient contrast ratios
