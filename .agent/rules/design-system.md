# Design System Rules

## Colors
- Primary: blue-600 (#2563EB)
- Background: white / gray-950 (dark)
- Text: gray-900 / gray-100 (dark)
- Muted: gray-500 / gray-400 (dark)
- Borders: gray-100 / gray-800 (dark)

## Typography
- Display: Geist. Body/editorial: Archivo 400. Small/caption: Archivo 500. Structured metadata and eyebrows: Geist Mono.
- Weights: 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
- Scale: xs(12), sm(14), base(16), lg(18), xl(20), 2xl(24), 3xl(30), 4xl(36), 5xl(48)

## Spacing
- Use Tailwind spacing scale (4px base)
- Section padding: py-24 md:py-32
- Card padding: p-6 or p-8
- Grid gaps: gap-8 or gap-6

## Components
- Cards: rounded-2xl, border, bg-white dark:bg-gray-900
- Buttons: rounded-xl, px-6 py-3
- Badges: rounded-full, px-3 py-1, text-xs
- Forms: rounded-lg, border, px-4 py-2.5
