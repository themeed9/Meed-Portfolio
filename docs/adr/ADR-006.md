# ADR-006 — CMS Editability Is Non-Negotiable

- **Status:** Accepted (implemented)
- **Date:** 2026-08-18
- **Context:** Admin pages and API routes under `app/admin/` and `app/api/` manage projects, case-study blocks, project images, site content, skills, services, testimonials, resume, and settings. Project sections and images are scoped per project and reorderable.
- **Decision:** Projects, copy, images, ordering, and case-study blocks remain editable without source-code changes.
- **Rationale:** The owner must be able to publish and revise portfolio content directly; this is a product requirement, not a convenience.
- **Alternatives:** Content-as-code (rejected: violates ADR-001); read-only CMS (rejected: contradicts the requirement).
- **Consequences:** Every mutation endpoint must be authenticated and validated; content ordering is a first-class field; a regression must not silently break editor workflows.
- **Constraints:** Editing a project must never require a new React page or a redeploy.
