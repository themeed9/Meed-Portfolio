# ADR-009 — Motion Is Purposeful and Restrained

- **Status:** Accepted (implemented)
- **Date:** 2026-08-18
- **Context:** The `product-portfolio-motion` skill (`skills/product-portfolio-motion/SKILL.md`) and `lib/motion.ts` define a small, shared motion vocabulary (durations 120–500 ms, a fixed easing set, opacity/transform-first). The public portfolio treats motion as explanation, not decoration.
- **Decision:** Motion supports hierarchy, comprehension, and feedback. It must not become decorative UI bloat.
- **Rationale:** Editorial restraint and readability are core to the approved design system; motion that cannot state its purpose should be removed.
- **Alternatives:** Decorative/playful motion systems (rejected by the taste direction); per-component invented durations (rejected by the motion skill).
- **Consequences:** Motion uses shared tokens; reduced motion is a first-class mode; page content/navigation is never delayed by animation.
- **Constraints:** Any motion change must follow the motion skill's review routine and reduced-motion requirements.

## Addendum (2026-11-27): owner-approved expressive motion

The owner asked for interaction and smooth animation similar to robin-noguier.com. This widens "restrained" for a defined set of effects. The patterns are borrowed; the design is our own, and there is no WebGL.

- **Momentum scrolling** (`lenis@1.3.27`, `components/layout/SmoothScroll.tsx`) on public pages only, never in the admin. It drives the native window scroll, so anchors, sticky elements, keyboard, find-in-page and assistive technology behave normally.
- **Velocity tilt and depth** on media marked `[data-parallax]`: at most ±3deg skew and a ±3% drift, eased back to rest when scrolling stops.
- **Greyscale-to-colour reveal** on Selected work images, a thin scroll-progress line, and a full-bleed project-colour hero on case studies, using the band's auto-picked AA text colour.
- **Unchanged constraints:** with `prefers-reduced-motion` none of the smoothing, tilt, drift or colour transition runs. Content and navigation are never delayed by animation.
